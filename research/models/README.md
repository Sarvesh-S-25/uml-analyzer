# Put your frozen .mdj diagrams here

One per project, named to match its entry in `research/corpus.json`:

    jabref.mdj
    teammates.mdj
    spring-petclinic.mdj
    ...

**Freeze them.** Recover each diagram from one early commit, note that commit's
SHA in `corpus.json`, and then never edit the file again. If the diagram changes
as the code changes, conformance is perfect by construction and the study
measures nothing.
